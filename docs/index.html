GOOD TO KNOW

“没找到”，和“没有”，差得很远。

这次能检查什么？

敏感词检查覆盖所选文件名，以及 UTF-8、带 BOM 的 UTF-16 文本；也检查文本中的 HTML 实体。支持常见网页、代码、Markdown、JSON、CSV 等纯文本。不会显示匹配原文。

Word 支持正文、表格文字、页眉页脚、脚注、尾注、批注与文本框；DOCX 另检查文档属性，DOC 不检查属性或已删除修订。PDF 支持文字层、批注、表单值与文档属性。PDF 前 20 页还会整页 OCR，包含扫描页和混合图文页。Word 内图片、文档内图片 GPS、宏与其他隐藏对象不在范围内。PDF 最多 100 页，DOCX 解压内容最多 32 MiB / 2000 项；提取文字最多 4 MiB，单文件处理最多 180 秒。

图像检查读取 JPEG、PNG、WebP 的 EXIF GPS 目录，包括只有部分 GPS 字段的情况；不展示经纬度。损坏的容器或无法解析的 EXIF 会列入未检查项。同时对图片做中英文 OCR；不检查 XMP、IPTC 或人脸。图片最多 1200 万像素，OCR 最长边 2400 像素。

什么需要另行检查？

支持 Word .doc / .docx 和 PDF 的可提取文字。加密或损坏文档、其他 Office 格式、压缩包和超限文件，会明确列出未检查原因与处理建议。OCR 可能漏字、错字，尤其是手写、模糊或复杂排版。无文字、低置信度、缩放和失败均列为需人工核对；置信度不是准确率。自动规则仅筛查候选，不验证身份或密钥有效性，也不能找出所有隐私。

浏览器只能读取你选中的文件，拿不到完整原始路径、Git 暂存区或历史。报告包含未被规则遮盖的文件名，分享前请人工核对。

03 / CHECK THE PAST, TOO

网页改好了，那历史记录呢？

原来的 Python 工具继续保留。它能检查目录、整个 Git 暂存快照，以及本地所有 refs 可达历史；也支持禁止公开的精确路径规则。

git clone https://github.com/ChenYueqi2024/before-public.git
cd before-public
python -m pip install .

# 在源码目录运行；将路径替换为自己的仓库与规则文件
before-public /path/to/repo --mode staged --config /private/rules.json --output /private/staged-report
before-public /path/to/repo --mode history --config /private/rules.json --output /private/history-report

需要 Python 3.10+ 与 Git。规则与报告请放在公开仓库外。它只检查，不自动删除文件或改写历史；远端未拉取分支、托管平台缓存与他人副本不在范围内。
